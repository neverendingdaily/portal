🧩 汎用ウィジェット スニペット

どのHTMLページにも貼るだけで「履歴・ワード登録・メモ」機能が追加できます

👁 このページで実際に動いています

右下のボタン 📌 をタップしてウィジェットを開いてみてください。下のコードを自分のサイトに貼ると同じように動きます。

💡 GitHub Pages の localStorageについて：
あなたのサイトがすべて username.github.io 配下にある場合、localStorage はドメイン単位で共有されます。 ウィジェットのキー名（xwg_words など）を統一すれば、どのサイトを開いても同じワード登録・メモが使えます。
🕐 ページ訪問履歴 📌 ワード登録 📝 メモ 🔗 localStorageで全サイト共有
📋 使い方 — 3ステップ
  • 1️⃣
    下のコードブロック右上の 「コピー」 ボタンをクリック
  • 2️⃣
    追加したいHTMLファイルを開き、</body> タグの直前にペースト
  • 3️⃣
    保存してブラウザで開くと右下に 📌 ボタンが現れます。以上！
🔗 全サイトでデータを共有するには： コードの先頭付近にある const XWG_KEYS のキー名を、すべてのサイトで同じ値にしてください（デフォルトのままでOK）。
同じ github.io ドメイン配下であれば自動的に共有されます。

⚙️ カスタマイズ可能な部分

    

      
変数・設定意味・変更例

      

        XWG_KEYS.words
        ワード登録のlocalStorageキー。全サイト共通にしたいなら同じ値を使う
      

      

        XWG_KEYS.memos
        メモのlocalStorageキー。同上
      

      

        XWG_KEYS.history
        履歴のキー。サイトごとに分けたい場合は 'xwg_hist_mysite' のように変える
      

      

        XWG_MAX_HIST
        履歴の最大保存件数（デフォルト 50）
      

      

        XWG_AUTO_HIST
        true でページを開いたとき自動記録、false で手動のみ
